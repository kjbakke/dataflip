# Changelog

## 0.1.0

First release.

- Data sources for PostgreSQL, MySQL / MariaDB, SQL Server, SQLite and Google BigQuery, with every database on a server listed in the sidebar
- Query consoles with schema-aware autocomplete; `Cmd/Ctrl+Enter` runs the statement under the cursor
- A tab for every table and every console's results
- Excel-style column filters, sorting, and `WHERE` / `ORDER BY` on whole tables
- In-place editing of rows, submitted in one transaction
- Add, rename and drop columns
- Saved consoles and query history
